# 차록 · 검증된 TEST 흐름의 한글 자막 시연

사용자 요청에 따라 **실제 Mac Pleos 화면으로 2분 39초 시연 영상을 만들고 완성 파일을 검증했습니다.** [영상 MP4·자막·검증 증거](evidence/macos-pleos-captioned-demo-2026-11-15/README.md). 앱은 기존0.3.1/7, 검증 코드8c8f793과 같은 APK입니다.

좌측 상단에는 시나리오 제목을 계속 표시하고, 하단에는 해당 동작을 설명하는 한글 자막을 넣었습니다. 원본 화면 바깥에 두 영역을 추가해 내비·버튼·차량정보를 가리지 않습니다. TEST 입력·실제 Pleos 화면·무음·버튼/알림 직접 조작을 전체 영상에 표시했습니다.

영상 번호는 이번 시연의 장면 번호입니다. [전체12개 시나리오 검증](19-background-fixes-and-reverification.md)의 통과한 TEST 동작을 묶었으며, 미완료인 실제 Gleo 발화·자동 우측 열기·마이크·차량 SDK·차록 Navi 목적지·외부 정비소 전달을 성공처럼 시연하지 않았습니다. 창 배치는 OS 수동 조작이라고 자막으로 밝혔습니다. 보이는 결과 알림은 직접 펼친 알림센터이며 자동 토스트가 아닙니다.

## 완성 파일 검사

- 전체 **3,820프레임** 디코딩 성공, 영상 시작/끝과 타임스탬프 확인.
- **17개 구간**의 한글 제목·자막을 최종 MP4에서 OCR로 읽어 모두 원문과 일치. 글리프 누락·대체 문자 없음, 자막 영역 넘침 검사 통과.
- 한국어 제목/자막이 영상 픽셀에 포함되므로 시청 기기 폰트에 의존하지 않음. 별도 UTF-8 SRT의17개 시간/텍스트도 일치.
- 주요 장면 시각 검토: 알림의 순간 표시/저장, 상담 내용, 재실행 잠금. 자막이 실제 화면을 가리지 않음.
- 기존 **118개 모든 행 보존**, 새 시연 TEST 기록1개만 추가해 **119개·무결성ok**. 종료와 재실행 뒤 같은ID·987건 관측 불변.

원본은 전체 디스플레이를 약493초 동안1,194장으로 연속 캡처했습니다. 실효2.42fps이며 24fps 출력에서 원본 시각을 유지하고 프레임 보간은 하지 않았습니다. 기다리는 구간만 시간 순서대로 잘라159.167초로 편집했습니다. M1 8GB·외장 SSD·기존 AVD 한 대를 유지하고, AVD를 정상 종료한 뒤 인코딩했습니다. 앱 코드를 바꾸거나 다시 설치하지 않았고 자동 병합하지 않습니다.
