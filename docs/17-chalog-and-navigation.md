# 차록 · CHALOG와 순정 내비 검증

> 명칭 변경 후속: 저장소·소스 이름은 0.3.2에서 chalog로 변경했습니다. 아래의 유지 결정은 당시 이력이며 현재 기준은 [이름 변경·호환 검증](21-chalog-rename.md)입니다.

## 브랜드

영문 브랜드는 **CHALOG**, 한글 이름과 Gleo 호출어는 **차록**으로 정했습니다. ‘차 + log(기록)’의 의미를 담은 조어입니다. 영문만 보면 ‘차로그’로 읽힐 수 있으므로 앱 헤더·소개·보고서에 두 이름을 함께 표시합니다. 상표 사용 가능 여부를 확인했다는 뜻은 아닙니다.

0.2.3/5에서 헤더, 보고서 제목, 영문 응답, schema 설명을 갱신했습니다. 새로 생성하는 보고서 파일명은 `chalog-<id>.txt/json`입니다. 한글 UI와 `invokeWord`는 차록입니다.

기존 설치와 기록을 이어가기 위해 `dev.leemh.charok`, 내부 클래스, Room DB·스키마, GitHub 저장소/브랜치 이름은 유지합니다. 기존 보고서 파일도 이동·삭제하지 않습니다. 코드 기준은 `1ed571d9d0ab4cc8aad7dcd7aa51530fb504ee42`입니다.

## 내비 기능과 지도 표시를 분리해서 확인

공식 [NaviHelper 소개](https://document.pleos.ai/api-reference/connect-sdk-pleos/NaviHelper/intro)는 목적지·경유지 설정과 경로 안내, 결과 이벤트를 지원합니다. 따라서 Pleos에서 내비를 동작시키는 것 자체가 불가능한 것은 아닙니다. SDK 요청의 연결 준비·콜백 확인과 순정 앱 직접 조작은 다른 검증입니다.

2026-11-15, 기존 Mac M1 8GB/외장 SSD의 `CharokPleosMac` 한 대에서 Pleos Connect 2.1.0 순정 내비(`ai.umos.maps.android.navigation.app`)를 직접 조작했습니다. 에뮬레이터의 기본 위치에서 공개 충전소를 검색했으며 실제 사용자 이동 경로가 아닙니다.

| 확인 항목 | 실제 관측 |
| --- | --- |
| 순정 앱 시작·네트워크 | 실행 성공. 네트워크 probe 통과와 내비 엔진/지도 초기화 완료 로그 |
| 장소 검색 | 충전소 목록과 장소 핀 표시 성공 |
| 목적지·경로 안내 시작 | 판교 아이스퀘어 전기차충전소 선택 후 340m·3분 경로, 회전 안내, 목적지 핀과 경로선 표시 |
| 안내 종료 | 순정 ‘안내 종료’ 버튼으로 이번 검증 경로 종료 |
| 배경 지도 | host 렌더링에서는 도로·건물 바탕이 비어 있음. 안내/검색 성공과 별개 문제 |
| 차록에서 NaviHelper로 목적지 요청 | 이번에는 수행하지 않음. 기존 차량 상태 미확인 잠금을 유지 |
| 실제 주행·음성 안내 | 미검증. 정지 에뮬레이터, 기존 오디오 문제로 `-no-audio` 유지 |

초기 로그의 `Service Not Found / Unauthorized`는 충전소 사업자 목록 API 경로였습니다. 이를 지도 타일 인증 실패나 전체 내비 사용 불가의 근거로 삼지 않습니다. NMEA 체크섬 오류와 OpenGL `0x501`도 관측했지만 단독으로 흰 지도 원인을 확정하지 않습니다.

## 지도 배경 비교 절차

같은 AVD·데이터를 보존하고 host에서 `-gpu swiftshader`로 한 번 비교했습니다. [Android 공식 문제 해결 문서](https://developer.android.com/studio/run/emulator-troubleshooting)는 그래픽 호환성 문제에 소프트웨어 렌더링을 제안합니다. 명령행 옵션만 비교했으며 AVD 설정 파일·앱 데이터·인증은 변경하지 않았습니다.

SwiftShader에서도 배경 지도는 표시되지 않았고, 이후 지도 면이 검게 변하며 `Failed to find ColorBuffer` / `invalid color buffer` 오류가 나타났습니다. 해결책으로 채택하지 않고 정상 종료 후 기존 host 모드로 돌아갔습니다. host에서도 배경 지도 누락은 남아 있어 원인을 확정하거나 해결했다고 표시하지 않습니다.

순정 APK의 지도 구성을 읽어 보려 했으나 일반 ADB 접근은 `Permission denied`였습니다. root·remount·키 복사로 우회하지 않았습니다. 후속 조사는 이 재현 화면, 이미지 버전, 렌더러 비교, 민감 정보를 제거한 오류를 Pleos 공식 기술 지원에 전달해 지도 데이터/스타일 제공 조건과 Mac ARM 지원 범위를 확인하는 것입니다. 지원 메시지는 아직 보내지 않았습니다.

## 후속 검증 기준

차록의 실제 SDK 차량/경고등 수신, 마이크 STT/TTS, Gleo 발화, 차록의 목적지 요청/콜백, 자동 우측 배치는 각각 별도 검증합니다. 순정 내비 직접 조작 성공을 이 항목의 성공으로 확대하지 않습니다. 차량정보는 왼쪽, 순정 내비는 그 오른쪽에 유지하고 차록은 명시적으로 열 때만 우측 콘텐츠 패널을 사용하는 제품 방향을 유지합니다.

이번 작업은 스크린샷으로 확인하며 새 영상을 만들지 않습니다. 다음 영상은 확인된 실제 동작만 사용하고 한국어 기능 자막과 TEST/순정 앱/SDK 입력 구분을 넣습니다.
