## 환경 문제와 종료

M1 8GB·외장SSD·기존 CharokPleosMac 한 대를 사용했습니다. 촬영 준비 중 ADB 연결이 끊기고 기존 VM이 정상 종료 요청에 응답하지 않아 해당 멈춘 VM만 종료했습니다. 그 VM의 고아 crashpad가 CPU를 계속 사용하여 TERM 실패 후 해당 프로세스만 종료했습니다. 같은 AVD 재실행 후133개 원본행의 완전 일치를 확인하고 촬영했습니다. 이 실패 시도에서는 새 기록을 시작하지 않았습니다. Gleo 자체 서비스의 초기화 오류도 실제 Gleo 성공과 구분했습니다.

작업 마지막에는 차록 수집·순정 내비 안내를 종료하고 `adb emu kill` OK, 프로세스 exit0·ADB기기없음으로 정상 종료를 확인했습니다. DB 삭제·앱 제거·인증 우회·키 복사는 하지 않았습니다. 원본DB·상세로그는 비공개 로컬 보관입니다.

## 검증 범위

영상은 **TEST 입력·버튼·직접 펼친 알림센터**입니다. 실제 Gleo 발화·등록, 실제 차량 SDK·마이크 연동, 음악 재생, 자동 우측 창 지정, 차록의 내비 목적지 전달, 외부 정비소 전송/예약 성공을 시연하지 않습니다. 오른쪽 창은 OS 수동 배치라고 자막에 표시합니다. 순정 내비340m 경로 안내는 동작하지만 바탕지도는 비어 있습니다. 짧은 자동 토스트는 미확인입니다. 문서 선택기 stub은 실제 파일 저장 성공이 아닙니다.
